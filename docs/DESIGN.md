# Aureole — design

## Why this game

Mothglass failed the “one more try” test (too opaque, too hard). Aureole uses a proven addictive loop (Stack / tower drop) with international art-casual presentation.

## Pillars

- **3-second teach:** swinging slab + Tap hint
- **Instant feedback:** Perfect / Good / fall
- **Rising tension:** swing speed climbs
- **Clean chrome:** score + ghost game-over only

## Non-goals

- Narrative chambers
- Tutorial walls of text
- Complex puzzle rules
