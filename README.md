# Aureole

Tap to stack glowing discs. Perfect alignment builds combo. Miss — fall. One more try.

International art-casual (EN default, VI optional). Godot 4.7+.

## Play

Open `project.godot` in Godot → F5. Click / tap / Space to drop.

## Loop

1. Disc swings.
2. Tap to drop onto the tower.
3. Overhang is cut. Perfect center = combo juice.
4. Speed rises. Beat your best.
